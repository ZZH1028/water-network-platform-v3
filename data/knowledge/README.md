# 知识库种子资料说明

本目录提供本项目自编的专业导读与平台操作帮助，供首次启动时建立检索索引。它不是全球水利文献全集，也未收录所引用机构网站的全部原文。导读不能代替有效规范、经审批调度规程、正式工程资料或经率定验证的专业模型。

## 覆盖范围

- 平原感潮河网、潮汐顶托、边界条件和坐标高程基准。
- 监测质量、洪潮组合、预报验证与不确定性。
- 闸泵联合调度、多目标冲突及安全审核。
- 本平台数据导入导出、预测调度、预警、三维资料和系统维护。

专业导读标记为 `Source-Type: reference_overview`，操作帮助标记为 `Source-Type: operation_manual`。每份正文有 `Source-URL`，它是参考或项目来源入口，不表示已获得或已索引该网站的全部内容。正文中另列的参考链接同样只提供阅读入口。此 README 为说明文件，不应作为专业问答证据索引。

## 导入与回答的含义

导入资料会提取文本、分段、保存来源和建立增量检索索引，不是训练或微调大模型。未配置模型时，系统应明确展示本地检索摘录；配置模型并允许发送本次资料片段时，可基于检索证据组织回答。所有结论仍需核对引用、版本、地区、高程基准和适用条件。找不到证据时，应说明资料不足，不能伪造引用。

管理员和科研人员可补充有权使用的教材、论文、规范、工程手册、当地河网和闸泵运行资料；建议记录标题、作者或发布机构、版本日期、来源链接、适用地区和使用限制。公开“水知AI助手”仅检索内置导读与操作手册；上传专业资料默认仅供已登录用户问答检索，管理员可移除上传资料及其索引。导入者应确认资料可向本平台已登录用户共享。扫描文档应先进行 OCR 并检查识别准确性。实际调度与控制必须按当地授权流程和正式规程执行。

平台空间页面统一为公开“实景三维”和后台“三维河网”，站点时序业务入口为“运行监测”。正文专业术语中的 GIS 指地理信息数据与空间参照，并不表示平台仍使用二维地图导航。
